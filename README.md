Важно: фотографии в исходном проекте были внешними ссылками на valmo-rus.ru; скачать их в сборочной среде не удалось. В архиве сохранены 75 исходных ссылок, **сами фото не вложены**. Плагин загружает их в Figma и не создаёт макет с отсутствующими фотографиями. Если загрузка не проходит, в комплекте есть download-photos.py и загрузка локальных изображений. Реальная доступность фото проверяется при запуске у пользователя.

## Загрузка на REG.RU

Распакуйте содержимое rustrak-regru-with-photos.zip непосредственно в корень сайта. В архиве нет дополнительной внешней папки: index.html, .htaccess, robots.txt, sitemap.xml лежат в корне, ресурсы — в assets/, обработчик формы — в api/.

Включите PHP 8+ и обработку .htaccess на Apache. Сохраните служебные файлы хостинга. Для ранее установленной версии желательно сначала сделать резервную копию, затем заменить файлы сборки, включая .htaccess.
