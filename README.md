## Последние правки: синие кнопки и согласия

- Все основные кнопки снова синие, с белым текстом. Золотистые акценты цен и характеристик сохранены.
- Каждая форма заявки содержит отдельный заметный флажок согласия на обработку персональных данных. Он изначально не отмечен. Без согласия нет запроса на отправку, PHP также отклоняет заявку с HTTP 422. В письме фиксируются согласие, редакция и время заявки.
- Добавлена панель cookie: необходимые данные и отдельный флажок аналитики. Аналитика по умолчанию выключена. Можно сохранить выбор или оставить только необходимые данные.
- Яндекс.Метрика и Вебвизор загружаются только после согласия на аналитические cookie. Отказ не мешает формам. Выбор сохраняется в браузере; изменить или отозвать согласие можно кнопкой «Настройки cookie» в подвале. При отзыве уже включённой аналитики страница перезагружается, чтобы остановить загруженный счётчик.
- Обновлена политика. Проверены выбор, отказ, повторный визит, отзыв и блокировка форм на ширинах 1440/390/320. Отдельно проверено отсутствие запросов Метрики при отключённом JavaScript.
- Отправка с отмеченным согласием проверена через локальный перехват почты, без реальных писем.

## Загрузка на REG.RU

Распакуйте содержимое rustrak-regru-with-photos.zip непосредственно в корень сайта. В архиве нет дополнительной внешней папки: index.html, .htaccess, robots.txt, sitemap.xml лежат в корне, ресурсы — в assets/, обработчик формы — в api/.

Включите PHP 8+ и обработку .htaccess на Apache. Сохраните служебные файлы хостинга. Для ранее установленной версии желательно сначала сделать резервную копию, затем заменить файлы сборки, включая .htaccess.
