# Курс 0.0 → редактируемый Zero Block

Комплект подготовлен для указанного исходника `concepts/g/index.html`: дневной перрон, исходные банки и шрифты. В ТЗ упоминается вечернее оформление; оно отличается от выбранного G. Вечерний вариант H в этот комплект не подмешивался.

## Что открыть сначала

- `index.html` — готовый предпросмотр с работающим переключателем банок. Можно открыть двойным кликом. В предпросмотре форма проверяет обязательные поля, но **не отправляет данные**.
- `IMPORT-ALL.html` — самодостаточный статичный HTML для импорта всей страницы. CSS, изображения и шрифты встроены; внешние CSS-файлы не нужны. JavaScript в этом файле отсутствует.
- `import-sections/01-hero.html` … `06-footer.html` — те же секции по отдельности. **Рекомендуемый путь:** один файл → один Zero Block. Так проще редактировать, настраивать якоря и проверять адаптивы.
- `assets/` — исходные WebP и WOFF2 для загрузки в проект Тильды.
- `PREPARE-IMPORT.html` — локальный помощник: собирает файлы импорта с прямыми URL загруженных вами ресурсов, если встроенные ресурсы не сохранились при импорте.
- `tilda/ADD-TO-T123.html` — небольшой код для переключателя и необязательной анимации. Его вставляют в T123, **не импортируют в Zero Block**.
- `ТЕКСТЫ.txt` — весь текст страницы отдельно.

## 1. Подготовьте Тильду

1. Создайте новую страницу в существующем проекте HANGAR. До импорта работайте с копией страницы, если в ней уже есть контент.
2. В профиле Тильды включите «Участвовать в тестировании новых функций»: по текущей документации это необходимо для HTML-импорта.
3. В настройках сайта → «Шрифты и цвета» → загрузка собственных шрифтов загрузите:
   - `assets/fuel.woff2`, семейство **Fuel** — заголовки и логотип;
   - `assets/pt-sans-narrow-regular.woff2`, семейство **PT Sans Narrow**, начертание Regular/400 — текст, кнопки и подписи.
4. Названия семейств в Тильде и исходном HTML должны совпадать. У Fuel исходная фактура с потёртостями — это часть шрифта. Дополнительный файл Bold отсутствует; не выбирайте другой шрифт для жирного текста.

## 2. Импортируйте секции

Для каждого из шести файлов:

1. Добавьте пустой Zero Block, откройте редактор.
2. В верхнем меню нажмите «…» → **«Импорт из HTML»**.
3. Загрузите соответствующий `.html` из `import-sections/`.
4. Нажмите «Подготовить к импорту».
5. Выберите **«Применить настройки к артборду»** и включите **«Уменьшить вложенность групп»**.
6. Используйте брейкпоинты 320, 480, 640, 960, 1200 px. В исходнике переходы заданы на 479/639/959/1199 px, то есть следующий диапазон начинается с 480/640/960/1200. Если Тильда предложит взять границы из файла, проверьте соответствие этим диапазонам в предпросмотре. Проверьте мобильный вид перед импортом.
7. Импортируйте, сохраните Zero Block. Проверьте высоту артборда: нижняя часть блока не должна обрезаться.
8. Повторите для следующего файла, сохраняя порядок 01 → 06. Между блоками уберите дополнительные отступы.

Если удобнее начать со всей страницы, загрузите `IMPORT-ALL.html` в один Zero Block тем же способом. Для навигации в одном длинном блоке используйте классы из шага 4 ниже. Для последующего редактирования отдельные секции удобнее.

**Импорт не равен вставке страницы картинкой:** текст, кнопки и изображения должны стать отдельными элементами Zero Block. Если получился единый HTML-элемент, выбран другой способ вставки — повторите через «Импорт из HTML».

## 3. Если изображения или шрифты не перенеслись

Поддержка встроенных data-ресурсов зависит от работы импортера; в вашем аккаунте она не проверялась. В готовых файлах всё встроено, но рассчитывать на автоматическую загрузку каждого ресурса без проверки нельзя.

1. В Тильде загрузите `apron-story.webp`, `cloud-story.webp`, `can-045.webp` как изображения. Скопируйте прямые HTTPS-адреса файлов из параметров изображений / опубликованной страницы. Не используйте адрес самой страницы.
2. Шрифты загрузите в настройках сайта. Если доступны прямые адреса WOFF2, скопируйте их также. Если таких адресов нет, оставьте поля помощника пустыми и назначьте уже загруженные шрифты элементам после импорта.
3. Откройте `PREPARE-IMPORT.html` двойным кликом, вставьте адреса, выберите секцию и нажмите «Скачать HTML для импорта».
4. Импортируйте полученный файл. Прямые URL позволяют импортёру обращаться к ресурсам без доступа к вашей локальной папке.
5. Если отдельная картинка всё равно не появилась, загрузите соответствующий файл из `assets/` в её элемент Zero Block вручную. Размеры и позицию сверяйте с `index.html`.

Файл банки 0,33 л понадобится отдельно на шаге 5.

## 4. Настройте якоря

Если секции импортированы в отдельные Zero Block, добавьте стандартный блок-якорь T173 непосредственно перед нужной секцией:

| Перед секцией | Имя якоря, без # |
| --- | --- |
| 02 — описание | `hg-story` |
| 03 — объёмы | `hg-product` |
| 05 — наличие и форма | `hg-availability` |

В ссылках меню уже стоят `#hg-story`, `#hg-product`, `#hg-availability`. Кнопка первого экрана ведёт к форме.

Если вся страница в одном Zero Block: назначьте соответствующим заголовкам CSS Class Name `hg-anchor-story`, `hg-anchor-product`, `hg-anchor-availability` (без точки). Код из T123 обработает переходы к этим элементам. Если в редакторе нельзя назначить CSS-класс элементу, используйте импорт по секциям с T173.

## 5. Включите переключение банок

Тильда не переносит JavaScript из HTML. В Zero Block остаётся стандартное изображение 0,45 л; второй слой и обработчик нужно подключить после импорта.

1. В секции 03 выделите **изображение банки**, не всю группу с текстом. В параметре CSS Class Name задайте **`hg-can-045`** без точки.
2. Дублируйте этот элемент. В копии замените изображение на `assets/can-033.webp` и задайте класс **`hg-can-033`**, удалив `hg-can-045` у копии.
3. На каждом адаптиве у обоих слоёв должны совпадать координаты и размеры. Прозрачные поля исходных WebP уже учтены; кадрирование — «Вписать/Contain», без растягивания самой банки.
4. У кнопок проверьте ссылки: **`#hg-volume-033`** и **`#hg-volume-045`**. Они используются как команды переключения, отдельные якоря для них не нужны.
5. У подписи «Сейчас на экране — 0,45 л» задайте CSS-класс **`hg-volume-caption`**: обработчик будет обновлять подпись. Если подпись импортировалась несколькими текстовыми элементами, замените её одним текстовым элементом перед назначением класса.
6. Добавьте **один T123 после всех Zero Block**. Откройте `tilda/ADD-TO-T123.html` как текст, скопируйте содержимое целиком в «Контент» блока T123. Не загружайте файл как картинку и не импортируйте его в Zero Block.
7. Опубликуйте тестовую страницу. В опубликованном виде 0,45 л видна по умолчанию, 0,33 л скрыта. Кнопки меняют видимую банку и активное состояние.

В редакторе оба слоя могут быть видны одновременно: T123 применяется на опубликованной странице. Для редактирования временно блокируйте верхний слой через панель слоёв. Не скрывайте вторую банку настройкой «не показывать на устройствах»: иначе переключателю нечего будет показывать.

Код не зависит от URL изображений и не затрагивает банку на первом экране. Текст кнопок и сами изображения остаются нативными элементами Zero Block.

## 6. Подключите форму

Импортёр может распознать HTML-форму как форму Zero Block. Проверьте результат. Если поля стали отдельными фигурами/текстом или не появился раздел приёмщиков, удалите только элементы макета формы и добавьте штатный элемент **Form** в тот же Zero Block.

Настройки формы:

| Поле | Тип | Обязательность | Имя переменной |
| --- | --- | --- | --- |
| Ваше имя | Однострочное текстовое | Нет | `Name` |
| Город | Однострочное текстовое | Да | `City` |
| Телефон или email | Однострочное текстовое | Да | `Contact` |
| Согласие на обработку персональных данных | Checkbox со ссылкой | Да, исходно не отмечен | `Consent` |

Не задавайте комбинированному полю Contact маску телефона или тип Email: поле принимает любой из двух вариантов. При желании его можно заменить двумя отдельными полями в редакторе.

- Текст кнопки отправки: **«Уточнить наличие»**. В исходном предпросмотре это безопасная демонстрационная кнопка без отправки. В Тильде назначьте её штатной кнопкой отправки формы.
- Ссылка согласия: `https://hangar-brw.ru/privacy` — перед публикацией владелец проекта проверяет, что документ применим к этой форме.
- Получатель: выберите подключённый в проекте сервис в «Настройки сайта → Формы», затем отметьте его в форме и перепубликуйте страницу. Почта из контактов не подключает приёмщик автоматически.
- Сообщение об успехе: **«Спасибо! Запрос отправлен. Мы свяжемся с вами по указанному контакту.»** Оно должно появляться только после успешного ответа сервиса Тильды.
- Для ошибок используйте штатное сообщение формы; при ошибке не показывайте успешную отправку.
- Параметры оформления: PT Sans Narrow, поля 21 px, подписи 17 px, высота поля от 50 px, фон белый, текст и рамка `#092b40`, кнопка `#092b40`, текст кнопки белый, фон секции `#04aee3`.

После публикации отправьте одну тестовую заявку, проверьте её фактическое поступление получателю и только затем считайте форму подключённой.

## 7. Верните анимацию

Статичные файлы импорта намеренно не скрывают контент и не содержат анимаций во время захвата. Анимация есть в `index.html`, а после импорта задаётся отдельно:

- Банке на первом экране назначьте CSS-класс **`hg-float`** — T123 добавит мягкое движение вверх-вниз, период 7 секунд.
- Фоновому изображению первого экрана назначьте **`hg-scene`** — T123 добавит плавное приближение, период 18 секунд. Артборд должен обрезать фон за своими границами.
- Для появления текста и секций используйте штатную базовую анимацию Zero Block: Fade In Up, смещение около 30 px, длительность около 0,75 секунды, без большой задержки. Не добавляйте вторую анимацию transform на слой, у которого уже включён `hg-float` или `hg-scene`.
- Код T123 отключает движение банки и фона при системной настройке «уменьшение движения».

Если импортёр превратил фон в фон артборда, не создавайте второй фон только ради анимации: оставьте его статичным или замените отдельным нативным изображением за контентом. Это ручная настройка, не автоматический результат импорта.

## 8. Параметры страницы

- Title: `Курс 0.0 — безалкогольный IPA | HANGAR BRW`.
- Description: `Безалкогольный IPA «Курс 0.0» от пивоварни HANGAR из Воткинска. Вкус, характеристики, объёмы 0,33 и 0,45 л. Уточните наличие в своём городе.`
- Один H1: «Курс 0.0» на первом экране. Остальные крупные заголовки — H2.
- Для рабочей страницы проверьте настройки индексации Тильды. Исходный `noindex,nofollow` из прототипа в комплект не перенесён. Для временной копии при необходимости включите запрет в её настройках.
- Баннер/режим cookies и возрастное предупреждение задайте на уровне проекта, если они используются на основном сайте. В комплекте нет аналитических трекеров и сторонних cookies.

## 9. Проверка после публикации

- 320, 390, 480, 640, 960, 1200, 1440 px: нет горизонтальной прокрутки, текст и изображения не обрезаны, поля не выходят за артборд.
- Шрифты Fuel и PT Sans Narrow загрузились, кириллица отображается.
- Меню и первая кнопка приводят к нужным секциям.
- Кнопки 0,33 / 0,45 меняют именно нижнюю банку, обновляют подпись и активный цвет. После изменения ширины выбор не сбрасывает видимость слоёв.
- Пустые обязательные поля и неотмеченное согласие блокируют отправку.
- Корректная тестовая заявка появилась у выбранного получателя.
- Телефоны, почта, карта, соцсети и ссылка для партнёров ведут по назначению.
- Формулировка крепости «не более 0,5%» подтверждена производителем: она сохранена из исходного макета, на странице-референсе не подтверждалась.

## Документация и границы проверки

Подготовлен и проверен локальный исходник. Импорт в конкретный аккаунт Тильды, его тариф/доступность бета-функции, сохранение data-ресурсов, результат преобразования формы и доставка заявок здесь не проверялись: доступ к проекту Тильды не предоставлен.

- Прямой HTML-импорт: https://help-ru.tilda.cc/zero/import-methods/html-file-import
- Альтернатива — расширение Chrome: https://help-ru.tilda.cc/zero/import-methods/browser-extension-import
- Расширение HTML to Tilda: https://chromewebstore.google.com/detail/html-to-tilda/jfoogglaogkhcfmioabgbgmiakhgnmkd
- HTML/JS через T123: https://help-ru.tilda.cc/html
- Источник описания и контактов: https://hangar-brw.ru/bez-alchogol

Если пункта «Импорт из HTML» нет, сначала проверьте участие в тестировании новых функций; затем используйте расширение по инструкции Тильды. Для локальных файлов Chrome может потребовать «Разрешить доступ к URL файлов» в настройках расширения. Если расширение не читает локальную страницу, откройте её через локальный сервер: в папке комплекта выполните `python -m http.server 8080` и откройте `http://localhost:8080/index.html`. Остановить сервер — Ctrl+C.
