# Курс 0.0 · HANGAR BRW → Tilda Zero Block

Готовая страница на основе концепции G и комплект для переноса в редактируемый Zero Block.

## Скачать и открыть

1. [Скачать готовый ZIP-комплект](https://github.com/yask1chw/test1/raw/refs/heads/main/kurs-00-tilda-zero.zip).
2. Распаковать архив.
3. Открыть **START.html** — предпросмотр, ссылки на секции и копирование кода переключателя.
4. Следовать [инструкции по переносу](ИНСТРУКЦИЯ.md).

Файлы HTML нужно открывать после скачивания: GitHub показывает исходный код страницы. Для этого проекта используйте ссылку на готовый ZIP выше; он содержит только комплект «Курс 0.0».

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | Предпросмотр страницы с переключением фасовки |
| `IMPORT-ALL.html` | Самодостаточный HTML для импорта всей страницы |
| `import-sections/` | Шесть секций для импорта в отдельные Zero Block |
| `assets/` | Изображения банок, иллюстрации, шрифты |
| `PREPARE-IMPORT.html` | Подстановка прямых HTTPS-ссылок на ресурсы |
| `tilda/ADD-TO-T123.html` | Переключение банок и анимация после импорта |
| `ИНСТРУКЦИЯ.html` | Пошаговая инструкция в браузере |
| `ТЕКСТЫ.txt` | Тексты страницы |
| `ПРОВЕРКА.json` | Результаты локальных проверок |

## Что изменено

Сохранены дневной авиационный сюжет G, исходные банки, шрифты и палитра. Добавлены характеристики IPA, текст о пивоварне, макет формы и контакты. Исправлены переносы заголовков на мобильных экранах.

Локальная проверка выполнена на ширинах **320, 390, 480, 640, 960, 1200 и 1440 px**. В аккаунт Тильды страница ещё не импортирована. Приёмщик формы требуется подключить в Тильде; предпросмотр не отправляет заявки. Крепость ≤0,5% сохранена из исходного макета и требует подтверждения производителем.

Развёрнутый перечень: [изменения и проверки](ИЗМЕНЕНИЯ-И-ПРОВЕРКИ.md).
