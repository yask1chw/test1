КУРС 0.0 · КОМПЛЕКТ ДЛЯ ZERO BLOCK

1. Откройте index.html — готовый предпросмотр. Заявки из него не отправляются.
2. Прочитайте ИНСТРУКЦИЯ.md — перенос по шагам.
3. В Zero Block выберите «… → Импорт из HTML» и загрузите IMPORT-ALL.html.
   Удобнее импортировать по одному файлы из import-sections/ в отдельные Zero Block.
4. Шрифты загрузите до импорта. После импорта подключите штатную форму Тильды.
5. Настройте переключение банок по инструкции и вставьте tilda/ADD-TO-T123.html
   через T123. Этот файл — код, его нельзя импортировать в Zero Block.
6. Если встроенные ресурсы не перенеслись, загрузите assets в Тильду и откройте
   PREPARE-IMPORT.html: он соберёт HTML с вашими URL без внешних сервисов.
