Перенос в редактируемый Zero Block

Сохранены дневной перрон, исходные банки, шрифты и цветовая гамма. Добавлены характеристики, блок о пивоварне, макет формы и контакты.

Открыть готовую страницуИнструкция по шагам
Это комплект для переноса. В аккаунт Тильды страница ещё не импортирована; локальная форма не отправляет заявки. Переключатель и анимация после импорта подключаются отдельно.

1. Загрузите шрифты

В настройках проекта Тильды добавьте Fuel и PT Sans Narrow под этими же именами. Затем импортируйте макет.

2. Импортируйте HTML

Zero Block → «…» → «Импорт из HTML». Рекомендуется импорт по секциям: одна секция в один блок. Выберите «Применить настройки к артборду» и «Уменьшить вложенность групп». Проверьте 320 / 480 / 640 / 960 / 1200 px.

Либо скачайте всю страницу одним HTML-файлом. Файлы содержат стили и встроенные ресурсы. Если картинки/шрифты не перенеслись, используйте помощник с URL ресурсов или загрузите их в элементы вручную.

3. Верните переключение объёма

  1. У нижней банки задайте CSS-класс hg-can-045.
  2. Дублируйте слой, замените картинку на can-033.webp, задайте копии класс hg-can-033. Координаты и размеры двух слоёв должны совпадать на всех адаптивах.
  3. У кнопок сохраните ссылки #hg-volume-033 и #hg-volume-045.
  4. Подписи «Сейчас на экране…» задайте класс hg-volume-caption.
  5. Скопируйте код ниже в один блок T123 после всех Zero Block и опубликуйте тестовую страницу.
Показать код для ручного копирования

Для анимации банке первого экрана назначьте класс hg-float, фоновому изображению — hg-scene. Подробности и якоря — в инструкции.

4. Подключите штатную форму

После импорта проверьте форму Zero Block или замените её штатным элементом Form: имя необязательно, город и контакт обязательны, согласие исходно не отмечено. Кнопка — «Уточнить наличие». Подключите приёмщик в Тильде и отправьте тестовую заявку. Макет сам по себе не настраивает доставку писем.

5. Проверьте опубликованную страницу

Два объёма, якоря, телефоны, карта и ссылки; отсутствие обрезки на мобильных; реальное получение заявки. Крепость ≤0,5% сохранена из исходного макета — перед публикацией сверить с производителем.
